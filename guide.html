What Lightning Search is

Lightning Search finds sounds in your library from inside Reaper as fast as you can type, lets you hear them through Reaper, and puts them on the timeline with one key.

It has two parts:

  • The search window in Reaper. A Reaper script you open with a shortcut. You type, the results update on every key, you listen with the arrow keys and press Enter to add a sound at the edit cursor.
  • The helper. A small program in the Windows notification area (the tray, by the clock). It reads your library folders once, keeps a search index of them, and keeps that index up to date as files are added, changed or removed. Reaper asks the helper for results, so searching never touches your disks.

Lightning Search reads the metadata already embedded in your files (by Soundminer, BaseHead, Reaper’s Media Explorer and similar tools): file name, description, category and CatID, keywords, library, designer and the rest. It never writes to your files and does not edit metadata.

Requirements

  • Windows 10 or 11, 64-bit.
  • Reaper 5.982 or newer (any edition, installed or portable).
  • The SWS extension, version 2.14 or newer: https://www.sws-extension.org.
  • ReaImGui, version 0.9 or newer, installed through ReaPack (Extensions > ReaPack > Browse packages, search for ReaImGui).
  • Sound files in WAV, Broadcast WAV, RF64, Wave64, AIFF or FLAC.

Installing

  1. Download LightningSearch-0.9.0-beta-setup.exe from the Gumroad page.
  2. Run it. The installer is not code-signed yet, so Windows SmartScreen may show “Windows protected your PC”. Click More info, then Run anyway. Some browsers also ask whether to keep the download: choose Keep.
  3. The installer finds your Reaper resource folders, including portable ones it can see. Tick each Reaper you want Lightning Search in; Add… picks another folder (the one that holds reaper.ini).
  4. It checks for SWS and ReaImGui in each folder and says which are missing. You can still install and add them afterwards.
  5. If Reaper is running, the installer asks you to close it first.
  6. On the last page, Start Lightning Search now starts the helper and opens its welcome window.

Lightning Search installs for your Windows user only, so it needs no administrator rights. The program goes in %LOCALAPPDATA%\Programs\Lightning Search; in each Reaper folder it adds UserPlugins\reaper_lightning.dll and Scripts\Lightning Search\. The next time Reaper starts, it adds the Lightning Search actions to the Action List by itself.

To update, run a newer installer over the old one. Your library index, settings, favorites and playlists stay.

First run

The helper’s welcome window walks through three steps:

  1. Add your library folders. Click Add library folder… and pick each folder that holds sounds. External and network drives work; when one is unplugged its sounds stay in the index, marked offline.
  2. Start scanning. The helper reads the metadata of every file. The progress page shows how many sounds it has found, how many are searchable already, and an estimate of the time left. You can search while it scans: results grow as it goes. A large library takes a while the first time (Andrew’s 276,000-file library on a USB drive took about two hours); after that, only changes are read.
  3. Open Lightning Search in Reaper. In Reaper, choose Actions > Show action list, type Lightning_Search and run Script: Lightning_Search.lua. To open it with a key, select it, click Add… under Shortcuts and press the keys. We suggest Ctrl+Shift+L (Reaper already uses Ctrl+Shift+F).

The helper then sits in the tray and starts with Windows, so it is always ready when Reaper is. You can turn that off in the helper’s settings or the tray menu.

The core loop

  1. Press your shortcut. The search window opens with the cursor in the search box.
  2. Type. Results update on every key.
  3. Press Down to move into the results. Each result plays as you reach it.
  4. Press Enter. The sound lands at the edit cursor on the selected track, and the window hides. Ctrl+Z in Reaper takes it back.

Click the ? icon by the cog at any time for a cheat sheet of every key, with your own shortcuts filled in. It also has Open the user guide, which opens this guide.

Searching

Type words and Lightning Search finds sounds whose name or metadata holds all of them. The last word matches as you type it: expl already finds explosions.

Type Finds
metal door sounds with both words, anywhere in their name or metadata
metal, wood sounds with either word (a comma means “or”)
-wood hides sounds that have the word
"glass break" the words side by side, in that order
impact (metal, wood) brackets group words: metal impact or wood impact
crash* crash, crashes, crashing… (a star at the end of one word)

Find every ending (Settings > Search, on by default) does the star for every word, so crash also finds crashes and crashing. Words after a minus stay exact.

Searching one detail

A name and a colon searches just that detail:

Type Searches
lib:boom or library:"Boom Library" the library name
cat:door the UCS category or subcategory
catid:DOORWood the exact CatID
desc:, kw:, filename:, fx:, designer:, mfr:, recordist:, mic:, notes:, subcat: description, keywords, file name, FX name, designer, manufacturer, recordist, microphone, notes, subcategory
dur:1s..5s, dur:<500ms, dur:>2m length (ms, s, m, h; a bare number is seconds)
ch:stereo, ch:mono, ch:>2 channel count
sr:48k, sr:44.1k..96k sample rate
bits:>=24 bit depth
type:flac, type:wav file type
vars:1, vars:>=10, vars:2..5 how many separate sounds (variations) the file holds
created:2024, modified:..2023-12-31 file dates (a year or month covers all of it)

Numbers and dates take >, >=, <, <= and ranges written a..b, a.. or ..b.

Thesaurus

The book button (Alt+T) turns the thesaurus on or off. With it on, helicopter also finds files that only say chopper or heli, ranked below the files that say helicopter. The line under the search box lists the extra words it searched. Settings > Search chooses the sources (word forms, UCS categories, sound design synonyms, your own groups) and lets you add your own groups or import a Soundminer .tth thesaurus.

Filters and sorting

The funnel button opens filters for file type, sample rate, bit depth, channels, length and variations. Each filter shows as a chip by the search box; its x removes it. Click a column header to sort by it, again to reverse, and a third time to go back to relevance.

Databases

The dropdown at the left of the search box picks a database: a named set of library folders to search, such as “Foley” or “Creatures”. All folders searches everything. Ctrl+1 to Ctrl+9 pick the first nine databases in the list. Make and edit them in Settings > Databases (or the helper’s settings window).

Listening

  • Down / Up move through the results and play each one; Page Down / Page Up move a page at a time.
  • Space plays or stops the highlighted sound.
  • Click the waveform to play from that point; drag across it to pick a range. A picked range is what plays and what gets added.
  • Left / Right step through a sound’s variations: the separate hits inside one file. “Skip initial silence” (Settings > Audition, on by default) starts each sound at its first variation. The Variations panel under the waveform sets how loud a hit must be and how long a gap separates two.
  • Reverse (R), the channel pick and Pitch also apply to what you add to the project. Loop (L) and Volume are only for listening.
  • FX (F) plays sounds through the selected track’s effects and fader, so you hear them as they will sound in the mix. Settings > Audition can send them through a dedicated “Lightning Search FX” track instead.
  • Sync (S) plays the sound with Reaper’s transport, starting a pre-roll before the edit cursor, so you hear it in place against picture and other tracks. Reaper’s own Play and Stop work too while Sync is on.

Lightning Search plays sounds through Reaper itself, on hidden audition tracks, so they come out of your usual audio device.

Adding sounds to the project

  • Enter adds the highlighted sound at the edit cursor on the selected track. With no track selected, it makes a new track for it.
  • New track (Ctrl+T) puts each sound on its own new track below the selected one, named after the sound.
  • Ctrl+click or Shift+click picks several results; Enter adds them one after another.
  • Settings > Workflow picks how you place sounds:
    • Spotting (the default): keys add at the edit cursor, and you can right-drag the waveform onto a track.
    • Drag to timeline: drag results straight from the list onto a track; the window folds away so you can see where you drop.
  • Each addition is one undo step in Reaper (Ctrl+Z), including any track it made.

Lightning Search never copies or converts files: items point at your library files where they are.

Favorites, playlists and databases

  • B (or the star at the start of a row) adds the highlighted sound to Favorites.
  • The panel button at the left of the search bar shows the sidebar: Library, Favorites and your folders and playlists. Right-click it for New playlist and New folder.
  • Right-click results for Add to playlist, or drag results onto a playlist in the sidebar.
  • Clicking a playlist searches inside it. With the search box empty it shows the playlist in its own order, and you can drag rows to reorder or press Delete to remove them.
  • A sound whose file has gone shows greyed out with its old name, so you can see what was there.
  • Favorites and playlists are kept by the helper and survive rescans, index rebuilds and updates.
  • The details panel (Ctrl+I) shows all of a sound’s metadata and its embedded artwork.

Settings

Open them with the cog in the search window. Every change applies at once. Each tab has Reset to defaults for that tab only.

The helper has its own settings window (click the tray icon): library folders and databases, how it keeps up with changes (live watching, or a daily check at a time you pick), scanning in the background at low priority, starting with Windows, the update check, and where its data lives.

Privacy

  • Your library, its index, your searches, favorites and playlists stay on your computer. Lightning Search has no account, no analytics and no usage tracking.
  • The update check (once a day; Settings > General can turn it off) downloads one small file from gla1wo.github.io saying what the newest version is. It sends nothing about you or your library; like any web request, it reveals your IP address to GitHub.
  • Bug reports are only made when you ask, and never sent by themselves. You see everything in the report before it is made, and you choose whether to attach it to the form. Library folders become <library 1>, other paths become <path>, and your user name, computer name and email addresses are removed. Searches and metadata never appear in the logs.

Lightning Search keeps its data in %LOCALAPPDATA%\Lightning: the catalogue and index, favorites and playlists, your thesaurus, logs and reports. The search window’s own settings live in Reaper’s reaper-extstate.ini.

Troubleshooting

“The helper isn’t running.” Start Lightning Search from the Start menu; the search window connects by itself. If it keeps stopping, send a bug report (below): it includes any crash notes.

A drive shows as offline. Its sounds stay listed, greyed and marked offline, until the drive is back. When it is, the helper checks it for changes by itself. To drop a drive you no longer use, remove its folder in the helper’s settings.

New files don’t show up. With live watching (the default), changes appear within about a minute. Network drives may not report changes: use Rescan now in the tray menu, or switch to a daily check in the helper’s settings.

The first scan is slow. Reading every file’s metadata takes time on large libraries, especially on USB or network drives. You can search while it runs. “Scan in the background” keeps it at low priority so Reaper never stutters; you can pause it from the tray menu.

Antivirus. Some antivirus tools briefly lock files Lightning Search is writing to its index; the helper waits and tries again. If your antivirus quarantines or blocks lightning-helper.exe or the installer, allow them: the builds are not code-signed yet.

Lightning Search is missing from Reaper’s Action List. Restart Reaper once after installing. If it is still missing, load Scripts\Lightning Search\scripts\Lightning_Search.lua with New action > Load ReaScript… in the Action List.

“ReaImGui is missing” or “SWS is missing”. Install them (see Requirements) and restart Reaper.

No sound when auditioning. Check Reaper’s audio device is running (Options > Audio device) and that its master output is not muted. Auditions play through Reaper.

Reporting a bug or sending feedback

Use Report a bug or send feedback… in the tray menu, or in the search window under Settings > General.

  1. Choose Bug, Idea or Other and write what happened.
  2. Show what will be sent shows the whole report.
  3. Create report saves a zip in %LOCALAPPDATA%\Lightning\reports, shows it in Explorer and opens the feedback form in your browser. Paste your message there and attach the zip. The form needs a Google sign-in to upload files.

Uninstalling

Open Windows Settings > Apps > Installed apps, find Lightning Search and choose Uninstall. It closes the helper, removes the program and the Reaper files it added, and takes its actions out of Reaper’s Action List. It asks whether to keep your library index, favorites, playlists and settings, in case you install again; choose No to remove them too. Your sound files are never touched.
